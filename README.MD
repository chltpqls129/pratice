# 부산 하루 여행 가이드

부산의 대표 여행지와 먹거리, 하루 추천 코스를 소개하는 반응형 웹 페이지입니다.  
해운대와 광안리의 바다, 감천문화마을의 골목을 둘러보는 여행 정보를 한 페이지에서 확인할 수 있습니다.

## 주요 기능

- 부산 여행지를 바다와 문화·관광 카테고리로 필터링
- 여행지별 상세 정보 펼쳐보기
- 부산 대표 먹거리와 하루 추천 일정 안내
- 여행 준비 팁과 FAQ 제공
- 다양한 화면 크기에 맞춘 반응형 레이아웃
- 키보드 및 보조 기술을 고려한 시맨틱 HTML과 ARIA 상태 표시

## 사용 기술

- HTML
- CSS
- JavaScript (Vanilla JS)

## 실행 방법

별도의 패키지 설치나 빌드 과정은 필요하지 않습니다.

1. 프로젝트 파일을 내려받거나 복사합니다.
2. `index.html`을 웹 브라우저에서 엽니다.

로컬 개발 서버를 사용하는 경우 프로젝트 폴더를 서버의 루트로 지정한 뒤 페이지에 접속하면 됩니다.

## 프로젝트 구조

```text
연습포트폴리오/
├── index.html       # 페이지 콘텐츠와 구조
├── style.css        # 레이아웃, 디자인, 반응형 스타일
├── app.js           # 여행지 필터, 상세 정보, FAQ 동작
├── images/          # 페이지에서 사용하는 부산 여행지 이미지
└── README.MD        # 프로젝트 안내 문서
```

## 참고

여행 코스와 방문 팁은 예시 정보입니다. 실제 여행을 계획할 때는 방문 장소의 운영 정보와 교통편을 미리 확인하세요.
